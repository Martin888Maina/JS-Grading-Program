

# JavaScript Student Grading System

Welcome to the JavaScript Student Grading System program! This program is designed to input a student's name and grade, and it calculates and displays the result (distinction, credit, pass, satisfactory, fail) based on the grading criteria.

## How to Use

1. Open the HTML file in a web browser.

2. Enter the student's name in the "Name" input field.

3. Enter the student's grade in the "Grade" input field.

4. Click the "CLICK HERE" button to calculate and display the result.

## Grading Criteria

- **Distinction:** Grades between 80 and 100.
- **Credit:** Grades between 60 and 79.
- **Pass:** Grades between 50 and 59.
- **Satisfactory:** Grades between 40 and 49.
- **Fail:** Grades below 40.
